## Classwork 11 - The Mandelbrot Set Repository

This repository contains a Python-based implementation developed as part of Unit 2 for the Programming course (Q2-2026). The objective of this assignment is to compute the Mandelbrot Set by iterating over a grid of complex numbers and saving the iteration count for each point into a CSV file.

## Project Description

The included Python script (`mandelbrot_set_math.py`) generates numerical data for the Mandelbrot Set.

The program performs the following steps:

* Reads the configuration values from `config.txt`.
* Stores the configuration parameters in a dictionary.
* Extracts the grid dimensions and iteration limit.
* Creates an output CSV file.
* Maps every pixel of the grid to a complex number.
* Applies the Mandelbrot iteration algorithm.
* Counts the number of iterations before each point escapes.
* Saves the row, column, and iteration count into the CSV file.
* Displays a completion message when finished.

## How to Run the Program

1. Ensure that Python 3 is installed on your system.

2. Clone this repository:

```bash
git clone https://github.com/Farah-on/UPY-PROGRAMMING-YAMIL-FARAH-Q2-2026.git
```

3. Navigate to the **Classwork-11-The-Mandelbrot-Set** directory:

```bash
cd Classwork-11-The-Mandelbrot-Set
```

4. Make sure the `config.txt` file is in the same folder as the Python script.

5. Execute the program:

```bash
python mandelbrot_set_math.py
```

6. After execution, the program will generate the file:

```
clase.csv
```

containing the iteration count for every point in the grid.
