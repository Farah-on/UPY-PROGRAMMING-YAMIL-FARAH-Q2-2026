# UPY-PROGRAMMING-YAMIL-FARAH-Q2-2026

## Classwork 12 - Mandelbrot Set Visualization Repository

This repository contains a Python-based implementation developed as part of Unit 2 for the Programming course (Q2-2026). The objective of this assignment is to visualize the Mandelbrot Set by reading the iteration data stored in a CSV file and converting it into an image using the Pillow library.

## Project Description

The included Python script (`mandelbrot_set_image.py`) generates an image of the Mandelbrot Set from the data produced in Classwork 11.

The program performs the following steps:

* Reads the configuration values from `config.txt`.
* Stores the configuration parameters in a dictionary.
* Opens the CSV file containing the Mandelbrot iteration data.
* Reads all rows and removes the header.
* Creates a new HSV image with the specified dimensions.
* Converts the iteration count into a brightness value.
* Assigns a color to each pixel based on its brightness.
* Converts the HSV image to RGB.
* Saves the final image as `mandelbrot-clase.png`.
* Displays a completion message.

## How to Run the Program

1. Ensure that Python 3 is installed on your system.

2. Install the Pillow library:

```bash
pip install pillow
```

3. Clone this repository:

```bash
git clone https://github.com/Farah-on/UPY-PROGRAMMING-YAMIL-FARAH-Q2-2026.git
```

4. Navigate to the **Classwork-12-The-Mandelbrot-Set** directory:

```bash
cd Classwork-12-The-Mandelbrot-Set
```

5. Make sure the following files are in the same folder:

* `config.txt`
* `clase.csv`

6. Execute the program:

```bash
python mandelbrot_set_image.py
```

7. After execution, the program will generate:

```
mandelbrot-clase.png
```

which contains the visualization of the Mandelbrot Set.
